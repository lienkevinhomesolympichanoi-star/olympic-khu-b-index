# Bản Đồ Quy Hoạch Chi Tiết Khu B - Thảo Nguyễn Vinhomes

Hệ thống hiển thị dữ liệu Bản đồ [dự án Vinhomes Olympic Hà Nội](https://lienkevinhomes.olympichanoi.com) dựa trên nền tảng Leaflet và Map Tiles từ QGIS. 

## 🚀 Các nâng cấp trải nghiệm người dùng
* **Hệ thống điều hướng 3 chiều:** 1. Mở rộng toàn màn hình (⛶). 
    2. Nút Back (➦) thông minh dẫn về [vinhomes olympic hà nội](https://lienkevinhomes.olympichanoi.com).
    3. Nút liên hệ trực tiếp qua Zalo.
* **📍 Định vị Location-Pin:** Chế độ hiển thị ON/OFF giúp người dùng kiểm soát quyền riêng tư và tiết kiệm pin khi đang xem [vị trí dự án vinhomes](https://www.lienkevinhomes.olympichanoi.com).
* **Độ mờ chuẩn xác:** Thanh trượt điều chỉnh độ mờ được cô lập sự kiện (stopPropagation) giúp thao tác vuốt chạm trên mobile mượt mà 100%.
